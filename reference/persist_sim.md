# Simulated persistence meta-analysis

A simulated meta-analysis of 60 studies reporting 1 to 5 pairs of
endline and follow-up effect sizes each, generated by
[`gh_simulate()`](https://joshgilbert1994.github.io/ghreg/reference/gh_simulate.md)
(see `data-raw/persist_sim.R`). Each pair comes from a simulated two-arm
trial of 40 to 200 participants whose outcome has a test-retest
correlation `rho` drawn from a Beta(6, 3) distribution (mean 0.67).

## Usage

``` r
persist_sim
```

## Format

A data frame with one row per pair of effect sizes:

- study:

  study identifier

- es_id:

  effect-size pair identifier

- n:

  participants in the trial

- rho:

  test-retest correlation of the outcome, which is also the sampling
  correlation of `es1` and `es2`

- es1, se1:

  endline effect size and its standard error

- es2, se2:

  follow-up effect size and its standard error

- theta1, theta2:

  true endline and follow-up effects

## Source

Simulated; see `data-raw/persist_sim.R` in the package source.

## Details

The data-generating values are `mu = 0.4`, `alpha = 0`, `beta = 0.4`,
`study_sd1 = 0.15`, `study_sd2 = 0.05`, `es_sd1 = 0.15`, and
`es_sd2 = 0.05`, so 40% of an endline effect persists to follow-up.
